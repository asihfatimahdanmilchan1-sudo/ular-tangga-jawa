# Ular Tangga Bahasa Jawa 🎲

**Pencipta:** Asih Fatimah  

Selamat datang di **game Ular Tangga versi Bahasa Jawa**!  
Game ini menggabungkan permainan klasik ular tangga dengan latihan kosakata bahasa Jawa.  

---

## 🎮 Cara Bermain
1. Pemain akan diberikan kata **bahasa Jawa ngoko**.  
2. Tugas pemain adalah menuliskan **kata krama** yang benar.  
3. **Jika jawaban benar:** pemain maju 1 kotak, dan bisa naik tangga jika berada di kotak tangga.  
4. **Jika jawaban salah:** pemain mundur 1 kotak, dan bisa turun jika berada di kotak ular.  
5. Pemain yang mencapai **kotak 100** lebih dulu **menang**.

---

## 📝 Kata Contoh
| Ngoko | Krama |
|-------|-------|
| turu  | sare  |
| lungguh | pinarak |
| mangan | dhahar |
| mlaku | tindak |
| ngombe | ngunjuk |
| krungu | midhanget |
| maca | maos |
